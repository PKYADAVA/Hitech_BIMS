{% extends 'base.html' %} {% load static %} {% comment %} Send a notification by hand. Everything else in this module is raised by a rule watching a number. This is the one place a person composes a message themselves — a delivery running late, a shed closing for maintenance — and addresses it down the organisation. Three columns, three questions, in the order they are actually answered: what am I sending, who is it for, and is that right. The third column is a preview, not a form: every number on it comes from the same helper the send uses (`alerthub.recipients.delivery_preview`), so the count the sender confirms is the count that goes out. **No permissions live on this page.** Who may open it is the Web-Access matrix; which people may be selected is the Employee Organization Access master. Both are read server-side — the dropdowns below only ever contain what the sender is already entitled to, and the form re-checks the posted ids on save. {% endcomment %} {% block title %}Send Notification — BIMS{% endblock %} {% block nav %}{% include 'main_top_navbar.html' with active_tab='alerts' %}{% endblock %} {% block content %}
