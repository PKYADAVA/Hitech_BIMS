Before you act
  • This tool only finds possible duplicates. Check the records themselves before changing anything.
  • A repeat is not always a mistake: two farmers can share a name, a supplier can reuse a bill number in a later year, and a flock can genuinely be treated twice in one day.
  • Deleting an entry moves every figure it fed — the flock count, the FCR and any settlement already run on it.
