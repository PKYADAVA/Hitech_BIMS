Installing it

  1. Tap Download above and wait for it to finish.
  2. Open the downloaded file.
  3. Android will ask to allow installing from this browser — allow it. You only need to do this once.
  4. Open Hi Tech BIMS and sign in with the same username and password you use on the website.

If it will not install

  1. Check there is room on the phone — it needs about 150 MB free.
  2. If an older copy is installed and refuses to update, uninstall it first.
  3. Ask your administrator to confirm your account is active.
